# Архив

Проекты, которые больше не участвуют в работе сайта. Код сохранён как есть, чтобы его можно было вернуть.

- `bot/` — торговый бот для OKX Futures (стратегии, бэктесты, alpha-исследования)
- `microstructure_bot/` — лаборатория микроструктуры рынка (итог: `results/no_edge_report.md`, преимущество не найдено)
- `execution_intelligence_lab/` — лаборатория поведения крупных участников
- `alpha_registry/` — реестр гипотез из лабораторий

Прогнозы цены теперь делает единый сервис `services/predictor` (обучение: `npm run predictor:train`).
